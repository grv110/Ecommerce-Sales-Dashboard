Project Overview

This project focuses on analyzing e-commerce sales data and building an interactive dashboard to identify sales trends, customer behavior, profit patterns, and business insights.

Objectives
Analyze sales performance
Identify profitable states and categories
Understand customer purchasing behavior
Track monthly profit trends
Monitor payment preferences


Tools Used

Power BI
Excel / CSV
Data Cleaning
DAX
Data Visualization
Dashboard Features

✔ Sales KPI Cards

✔ State-wise Sales Analysis

✔ Monthly Profit Analysis

✔ Customer Analysis

✔ Category Analysis

✔ Payment Mode Distribution

✔ Interactive Filters and Slicers

Key Insights
Highest sales generated from Maharashtra
Clothing category contributes major quantity share
COD is the most used payment method
Profit decreases during some months indicating seasonal variation
